# Sortopia — الست خوارزميات

Interactive study site for the six sorting algorithms of **Algorithms Design & Analysis**: Bubble, Selection, Insertion, Merge, Quick and Heap Sort.

- The course **C++** code runs line by line with an animated visual trace
- Variables, call stack, trace table and program output at every step
- Challenge mode: predict each comparison before it happens
- Sorting race: all six algorithms on the same array
- Question bank (MCQ, true/false, essay, tracing) with answers and explanations in Arabic

## Run

No build step. Open `index.html` in a browser, or serve the folder:

```bash
python -m http.server 5090
```
